Pendências recentes

Disponibilidade por EPI

Registrar novo empréstimo

Selecione um cadastro existente ou digite um novo. Os novos dados serão cadastrados ao confirmar o empréstimo.

Inclua quantos tipos de EPI precisar. Cada item terá seu próprio saldo e devolução, mas todos estarão vinculados ao mesmo atendimento.

Empréstimos e devoluções

Cadastro e movimentação de estoque

Para cadastrar um novo EPI, digite o nome e defina o estoque inicial. Para atualizar, use exatamente o mesmo nome. Perdas registradas nas devoluções já são descontadas automaticamente.

EPIs excluídos / arquivados (reativar)

Use “Editar” para corrigir nome e estoque mínimo. Use “Excluir” para retirar um EPI da lista ativa. Se houver histórico, o cadastro será arquivado e poderá ser reativado, preservando empréstimos e relatórios. Faça backup antes de excluir.

Relatórios de empréstimos

Consulte os empréstimos por período e filtre por motorista, transportadora, placa e EPI. As datas consideram o registro do empréstimo.

Para gerar PDF, clique em “Imprimir / Salvar PDF” e selecione “Salvar como PDF” na janela de impressão do navegador. O Excel exportado é compatível com o formato XML Spreadsheet 2003 (.xls).

Backup e segurança

Exporte o histórico em CSV para abrir no Excel ou salve um backup JSON para restaurar este sistema.

A importação substitui os dados atuais, após confirmação. O CSV é um relatório, não um backup restaurável.

Cuidados operacionais

Inspecione e higienize os EPIs antes de disponibilizá-los novamente, quando o compartilhamento for permitido. Controle acesso aos dados pessoais e mantenha cópias de segurança em local autorizado pela empresa.

BASE DA OPERAÇÃO

Cadastros

Informações reutilizáveis para agilizar cada empréstimo.

Inative cadastros para impedir novos empréstimos e manter o histórico. A exclusão está disponível somente para cadastros sem vínculos.

Preferências da operação

Personalize a identificação da unidade e agilize o preenchimento.

Armazenamento

Banco compartilhado · sem login

Os dados são gravados no banco PostgreSQL pela API. Todos os computadores que abrem este site consultam a mesma base. O backup JSON inclui cadastros, empréstimos, estoque e preferências.

O acesso é direto, sem conta e sem página de login. Quem tiver acesso ao endereço poderá consultar e alterar os registros.

Novo cadastro

Devolução por atendimento

Preencha as quantidades devolvidas ou perdidas. Deixe zero nos itens que continuam emprestados.

Editar EPI cadastrado

O estoque inicial e as movimentações permanecem inalterados. Para corrigir quantidades, utilize as movimentações de estoque.
